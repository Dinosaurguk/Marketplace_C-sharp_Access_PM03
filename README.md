## Возможности системы

### 🛍 Покупатель
- Просмотр каталога товаров различных категорий (электроника, дом, одежда, спорт и др.)
- Умный поиск по названию, артикулу, категории и бренду
- Карточка товара (двойной клик по строке) с проверкой актуального остатка
- Корзина: добавление позиций, изменение количества, удаление
- Оформление заказа: ввод адреса и телефона, выбор способа оплаты, автоматический расчет стоимости доставки (`300 ₽`) и итоговой суммы
- Отслеживание статусов своих заказов

### 📦 Продавец
- Просмотр и управление **только своими** товарами (`id_seller`)
- Добавление новых позиций в каталог с указанием остатков на складе
- Сборка заказов с автоматической проверкой наличия товаров на складе
- Назначение курьера на собранный заказ

### 🚚 Курьер
- Просмотр только назначенных на него заказов и адресов доставки
- Пошаговое обновление статуса доставки: `В сборке` → `Доставляется` → `Выполнен`

## Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Dinosaurguk/Marketplace_C-sharp_Access_PM03
   ```
2. Откройте решение `Vulpes0.sln` (или `Vulpes0.slnx`) в **Visual Studio**.
3. Убедитесь, что файл базы данных `Маркетплейс.accdb` находится в выходной директории сборки (`bin\Debug` или `bin\x64\Debug`).
4. Запустите проект клавишей **F5**.

## Стек и архитектура

- **Язык и платформа:** C# / .NET Framework 4.7.2, Windows Forms
- **База данных:** Microsoft Access (`.accdb`) через `System.Data.OleDb`
- **Работа с данными:** `DataSet`, `TableAdapter`, динамическая фильтрация через `BindingSource.Filter`
- **Бизнес-логика:**
  - Разграничение прав доступа и видимости вкладок на основе статической сессии `UserSession`
  - Автоматическая генерация номера заказа (`MP-2026-XXX`)
  - Транзакционное списание остатков со склада (`stock - kolvo`) и очистка корзины после оплаты
